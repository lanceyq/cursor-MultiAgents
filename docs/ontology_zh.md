# 本体

## 谓词

| 谓词 | 定义 |
|---|---|
| IS_A | 表示两个实体之间的类或类型关系（例如，“Model Y IS_A electric-SUV”）。包括“is”和“was”。 |
| HAS_A | 表示两个实体之间的部分-整体关系（例如，“Model Y HAS_A electric-engine”）。包括“has”和“had”。 |
| LOCATED_IN | 指定地理或组织上的包含或邻近关系（例如，“headquarters LOCATED_IN Berlin”）。 |
| HOLDS_ROLE | 将个人与其在组织内的正式职位或头衔联系起来（CEO、主席、董事等）。 |
| PRODUCES | 表示一个实体制造、建造或创造一个产品、服务或基础设施（包括规模扩大和组件包含）。 |
| SELLS | 标记产品或服务的商业卖方与客户之间的关系（市场、分销、销售）。 |
| LAUNCHED | 记录产品、服务或倡议的正式首次发布、装运或公开启动。 |
| DEVELOPED | 显示技术、产品或能力的设计、研发或创新来源。包括“researched”或“created”。 |
| ADOPTED_BY | 表示一个技术或产品已被另一个实体采纳、部署或实施。 |
| INVESTS_IN | 表示资本或资源从一个实体流入另一个实体（股权、融资轮、战略投资）。 |
| COLLABORATES_WITH | 实体之间的通用伙伴关系、联盟、合资或许可关系。 |
| SUPPLIES | 记录供应商-客户供应链链接或依赖关系（提供给、来源于）。 |
| HAS_REVENUE | 将实体与收入金额或指标（实际、报告或预测）关联起来。 |
| INCREASED | 表示相对于前期或基线的指标（收入、市场份额、产出）的向上变化。 |
| DECREASED | 表示相对于前期或基线的指标的向下变化。 |
| RESULTED_IN | 记录一个事件或因素导致特定结果（正面或负面）的因果关系。 |
| TARGETS | 表示一个实体寻求达到的战略目标、市场细分或客户群体。 |
| PART_OF | 表示层次结构成员或子集关系（部门、子公司、由...管理、属于）。 |
| DISCONTINUED | 表示产品、服务或关系的正式生命周期结束、关闭或终止。 |
| SECURED | 标记一个实体成功获得资金、合同、资产或权利。 |
| MENTIONS | 表示在文本或文档中引用或提及一个实体。 |
| FEELS | 表示对一个实体的主观意见或感觉（例如，“I feel like X”）。包括“THINKS”。 |
| HELPS | 表示通过提供服务或资源使（某人）更容易或可能做某事的行动。包括“assist”、“aid”和“support”。 |
| IS_DOING | 表示关于一个实体的主观行动或活动（例如，“I am doing X”）。包括“DOES”。 |
| LIKES | 表示喜欢或赞成某事或某人（例如，“I like roses”）。包括“LIKES”。 |
| DISLIKES | 表示不喜欢或不赞成某事或某人（例如，“I dislike roses”）。包括“DISLIKES”。 |

## 标签

### 情节标签

| 标签 | 定义 | 日期处理指南 | 日期处理示例 |
|---|---|---|---|
| FACT | 客观且可通过证据独立验证或证伪的陈述。 | 这些陈述可以由多个静态和动态时间事件组成，例如标记事实陈述描述的开始、结束和持续时间。 | “公司A在2022年拥有公司B”、“X导致Y发生”或“约翰在事件中说了X”是可验证的事实，除非我们有相反的事实，否则目前仍然成立。 |
| OPINION | 包含个人意见、感觉、价值观或判断的陈述，这些陈述无法独立验证。它还包括假设和推测性陈述。 | 这个陈述总是静态的。它是发表意见日期的记录。 | “我喜欢公司A的战略”、“X可能导致Y发生”或“事件感觉像X”是意见，取决于报告者的解释。 |
| PREDICTION | 关于未来可能发生的某事的不确定陈述、假设性结果、未经证实的说法。它包括解释和建议。如果陈述的时态改变，陈述将变为事实。 | 这个陈述总是静态的。它是做出预测日期的记录。 | “据传戴夫下个月将辞职”、“公司A预计X会发生”或“X暗示Y”都是预测。 |

### 时间标签

| 标签 | 定义 | 日期处理指南 | 日期处理示例 |
|---|---|---|---|
| STATIC | 通常是过去时态，思考-ed动词，描述单个时间点。这些陈述从发生之日起有效，并且永远不会失效。指事件发生的单个时间点，事实X在该日期发生将永远成立。 | valid_at日期是事件发生的日期。invalid_at日期是None。 | “约翰于2024年1月4日被任命为CEO”、“公司A报告上一财年增长X%”或“X导致Y发生”在发生当天有效，并且永远不会失效。 |
| DYNAMIC | 通常是现在时态，思考-ing动词，描述一段时间。这些陈述在特定时间段内有效，通常被标记事件结束或矛盾新事件开始的静态事实所否定。陈述可能已经指一个离散的时间段（无效）或可能是一个持续的关系（尚未无效）。 | valid_at日期是事件开始的日期。invalid_at日期是事件或关系结束的日期，对于正在进行的事件，此值为None。 | “约翰是CEO”、“公司A仍然是市场领导者”或“X持续导致Y减少”从事件开始时有效，并被新事件所否定。 |
| ATEMPORAL | 无论时间如何都将永远成立的陈述，因此没有时间界限。 | 这些陈述被假定为非时间的，没有时间界限。它们的valid_at和invalid_at都是None。 | “股票代表公司的所有权单位”、“地球是圆的”或“欧洲是一个大陆”。这些陈述无论时间如何都是真实的。 |
