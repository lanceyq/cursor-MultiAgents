# Claude Code 功能说明

## 代码开发
- 编写新功能和组件
- 修复bug和错误
- 重构和优化代码
- 添加测试用例
- 代码审查和分析

## 文件操作
- 读取、编辑、创建文件
- 搜索代码库（支持正则表达式）
- 批量文件修改
- Jupyter notebook编辑

## 开发工具
- 执行bash命令
- Git操作（提交、分支、PR等）
- 包管理（npm、pip等）
- 构建和测试

## 网络功能
- 获取网页内容
- 网络搜索
- API调用

## 项目管理
- 任务规划和跟踪
- 代码风格配置
- 多步骤任务自动化

## 安全限制
- 仅支持防御性安全任务
- 不创建恶意代码
- 不协助凭证发现

## 获取帮助
- 输入 `/help` 获取使用帮助
- 反馈问题：https://github.com/anthropics/claude-code/issues
